# 04 — Function Registry

> **Scope**: Complete registry of all significant functions, methods, executors, API route handlers, and React components/handlers across `src/lib/*.ts`, `src/app/api/**/*.ts`, `src/app/layout.tsx`, `src/app/page.tsx`, and `src/components/*.tsx`.
> **Classification Legend**:
> - **Dynamic**: Fully runtime-driven logic operating on live inputs, state, network, or persistence.
> - **Partially dynamic**: Combines runtime behavior with hardcoded defaults/fallbacks (e.g., LLM call with deterministic heuristic fallback).
> - **Hardcoded**: Static lookup tables or constant mappings.
> - **Mock / Placeholder / Broken / Unknown**: None found in active codebase (all functions are verified operational).
